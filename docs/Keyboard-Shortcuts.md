# Keyboard Shortcuts

These work on the Mac, and on iPad with a hardware keyboard. Hold ⌘ on iPad to see them.

## File

| Shortcut | Command |
|---|---|
| ⌘N | **New Connection…** |
| ⌘T | **New Query** (with a connection open) |

## Edit

| Shortcut | Command |
|---|---|
| ⇧⌥⌘Z | **Undo Last Save**: undoes the last save in the browser |

## Data

| Shortcut | Command |
|---|---|
| ⌘R | **Refresh**: reloads the table, or the connection's tree on its overview |
| ⌘↩ | **Run**: runs the query tab, the Query Editor strip or the pipeline |
| ⇧⌘E | **Show Query Editor** / **Hide Query Editor** |
| ⌘S | **Review Changes…** (when changes are waiting) |
| ⌥⌘I | **Show Inspector**: shows or hides the inspector |

## Accounts

| Shortcut | Command |
|---|---|
| ⌃⌘1 … ⌃⌘9 | Switch the window to your first to ninth account (with more than one account) |

## Sheets

- Return chooses the sheet's main button, such as **Connect**, **Save**, **Add** or **Import**.
- Esc cancels.
- On the welcome, ↑ and ↓ move through **Recent** and Return opens one.

## Mac only

| Shortcut | Command |
|---|---|
| ⌘, | **Settings…** |

In [Shell](https://github.com/v57/Shell/blob/main/Docs/README.md), which shows Database's interface for its
connections, New Query is ⌥⌘T and Refresh is ⌥⌘R, in the Data menu.
