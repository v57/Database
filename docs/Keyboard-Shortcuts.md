# Keyboard Shortcuts

The menu commands below have the same shortcuts on the Mac, on Linux and Windows (where Ctrl takes the place of ⌘),
and on iPad with a hardware keyboard.

## File

| Shortcut | Command |
|---|---|
| ⌘N | **New Connection…** |
| ⌘T | **New Query** (with a connection open) |

## Edit

| Shortcut | Command |
|---|---|
| ⇧⌥⌘Z | **Undo Last Save**: undoes the last save in the browser |

## Data

| Shortcut | Command |
|---|---|
| ⌘R | **Refresh**: reloads the table, or the connection's tree on its overview |
| ⌘↩ | **Run**: runs the query tab, the Query Editor strip or the pipeline |
| ⇧⌘E | **Show Query Editor** / **Hide Query Editor** |
| ⌘S | **Review Changes…** (when changes are waiting) |
| ⌥⌘I | **Show Inspector**: shows or hides the inspector |

## Sheets

- Return chooses the sheet's main button, such as **Connect**, **Save**, **Add** or **Import**.
- Esc cancels.
- On the welcome, ↑ and ↓ move through the list once it has focus, and Return opens the connection.

## On the Mac

<!-- only: mac -->

| Shortcut | Command |
|---|---|
| ⌘, | **Settings…** |
| ⌃⌘1 … ⌃⌘9 | Switch the window to your first to ninth account (with more than one account) |

<!-- /only -->

<!-- only: linux -->

On Linux, Ctrl+, (**Edit ▸ Preferences…**) opens Settings.

<!-- /only -->

<!-- only: windows -->

Database for Windows has no Settings window.

<!-- /only -->

In [Shell](https://github.com/v57/Shell/blob/main/docs/README.md), which shows Database's interface for its
connections, New Query is ⌥⌘T and Refresh is ⌥⌘R, in the Data menu.

## On iPhone and iPad

With a hardware keyboard on iPad, the File, Edit and Data shortcuts above work, and ⌃⌘1 … ⌃⌘9 switch the window to
your first to ninth account. Settings is the **Settings** button at the foot of the sidebar; it has no shortcut.
